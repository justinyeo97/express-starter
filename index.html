NomNom Endpoints Guide

GET Endpoints

GET /recipes

Retrieve all recipes as an array of objects.

Method: GET
URL: /recipes
Response (JSON):
[
  {
    "id": 1,
    "name": "Spaghetti",
    "ingredients": "Pasta, Tomato Sauce",
    "author": 1,
    "category": 2,
    "instructions": "Boil pasta, add sauce"
  },
  {
    ...
  }
]

GET /recipes/:id

Retrieve a specific recipe as an object

Method: GET
URL: /recipes/:id (in this example: id = 1)
Response (JSON):
[
  {
    "id": 1,
    "name": "Spaghetti",
    "ingredients": "Pasta, Tomato Sauce...",
    "author": 1,
    "cuisine": "Japanese",
    "instructions": "Boil pasta, add sauce..."
  },
]

GET /users

Retrieve all users as an array of objects.

Method: GET
URL: /users
Response (JSON):
[
  {
    "id": 1,
    "username": "mr.tungtung",
  },

  {
    "id": 2,
    "username": "tralalero tralala"
  }
]

GET /cuisines

Retrieve all cuisines as an array of objects.

Method: GET
URL: /cuisines
Response (JSON):
[
  {
    "cuisine": "Italian",
    "id": 1
  },

  {
    "cuisine": "Mexican",
    "id": 2
  }
]

POST Endpoints

Add a new recipe

Method: POST
URL: /recipes
Body (JSON):
{
  "name": "Spaghetti",
  "ingredients": "Pasta, Tomato Sauce...",
  "author": 1,
  "cuisine": "Italian",
  "instructions": "Boil pasta, add sauce..."
}

Add a new user

Method: POST
URL: /users
Body (JSON):
{
  "id": 1,
  "username": "mr.tungtung",
}
